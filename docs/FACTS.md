# Facts

Generated by `scripts/build_facts.py` from the records in this repository; do not edit by hand. Each value names the file it is computed from and the frozen setting it depends on (freeze records are named relative to `data/evaluation/`). README.md and the files in `docs/` mark a quoted value with an HTML comment, `<!-- fact: key -->`, just before the number, and `tests/test_facts.py` checks every marked number against this list, rounded to the decimals the document prints.

Accuracy figures are on NVIDIA's synthetic warehouse footage, except in the detector v4 section, which also reports two real-image test sets (LOCO and keremberke) and NVIDIA SmartSpaces (a re-used test). Times are CPU measurements on our Intel Core i7-10700 workstation, which was shared with other work, except in the UGen300 section: those were measured on the device over USB with a source advertising 0.9 A, so HailoRT ran it in reduced-performance mode; re-measure on a 3 A USB-C port before quoting them as the device's speed.
